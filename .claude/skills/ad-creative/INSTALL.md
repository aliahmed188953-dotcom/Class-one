# Install

Copy the `ad-creative` folder into your project:

    .claude/skills/ad-creative/

(or `~/.claude/skills/ad-creative/` to use it in every project)

Start a new Claude Code session. Verify with `/skills`.
Invoke with `/ad-creative`, or just ask for ads — Claude loads it automatically.

Requires Python 3 with Pillow:  pip install pillow
